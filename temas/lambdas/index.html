Lambdas en C++

Una lambda es una función sin nombre que se escribe justo donde se usa. No es una estructura de datos, pero la vas a ver en todos los temas que siguen: así se le dice a std::sort cómo ordenar, a std::count_if qué contar o a std::priority_queue quién tiene más prioridad.

Una función sin nombre

[capturas](parámetros) -> tipo { cuerpo }

Los corchetes dicen qué variables de afuera puede usar, los paréntesis qué recibe en cada llamada y el cuerpo qué hace. El tipo de retorno casi nunca se escribe: el compilador lo deduce del return.

Escribir la lambda crea un objeto función (por eso se guarda en una variable con auto), pero el cuerpo todavía no corre. Se ejecuta recién al llamarla, como cualquier función: con su propio marco en la pila.

Capturar por valor: [factor]

Una lambda no ve las variables de la función donde se escribe, salvo que las capture. Con [factor] guarda una copia en el momento en que se crea: si después cambias factor, la lambda no se entera. [=] copia todo lo que use.

¿Y si dentro del cuerpo escribieras factor = 5;?

Capturar por referencia: [&total]

Con & la lambda no se lleva una copia: guarda dónde está la variable original (la flecha). Así puede modificarla, como aquí, donde cada llamada suma a total. [&] captura así todo lo que use.

Lambdas anidadas: una dentro de otra

El cuerpo de una lambda puede definir y llamar a otra. cuadrado es una variable local de sumarCuadrados: se crea cada vez que esta se ejecuta y se destruye cuando termina. Cada llamada abre su propio marco en la pila.

Lambdas anidadas: una que fabrica otras

Una lambda puede devolver otra lambda. crearSumador(10) fabrica una función que suma 10, y crearSumador(3) otra distinta que suma 3: cada una recuerda su propia b, aunque el marco donde se creó ya no exista.

Uso práctico: contar con std::count_if

Los algoritmos de <algorithm> saben recorrer; la lambda les dice qué buscar. count_if llama a la lambda con cada elemento y cuenta cuántas veces devolvió true. Se escribe ahí mismo, como argumento, y captura limite para compararlo.

Si numeros tiene 1000 elementos, ¿cuántas veces llama count_if a la lambda?

Uso práctico: buscar con std::find_if

find_if pregunta a la lambda elemento por elemento y se detiene en el primero que cumple. Devuelve un iterador a ese elemento, o numeros.end() (la posición después del último) si ninguno cumple.

Capturas, costo y dónde las vas a usar

CapturaQué guarda la lambda
[]Nada: solo usa sus parámetros.
[x] / [=]Una copia de x / de todo lo que use. Sirve aunque la variable muera antes que la lambda.
[&x] / [&]Una referencia: puede modificar el original y no copia nada grande. Solo si la variable vive más que la lambda.
[x, &y]Mezcla: copia de x, referencia a y.
[x]() mutableUna copia que la lambda sí puede modificar.
[](auto a, auto b)Lambda genérica (C++14): sirve para cualquier tipo.
Con una lambdaTiempoLo vas a ver en
std::count_if, std::for_eachO(n)Recorridos: una llamada por elemento
std::find_ifO(n)Búsquedas: se detiene en el primero que cumple
std::sort(…, comp)O(n log n)Ordenamiento: unas n·log n comparaciones
std::priority_queue con decltype(comp)O(log n)Montículo: un min-heap con x > y
  • Crear una lambda es O(1): es un objeto que solo guarda sus capturas. Llamarla cuesta lo mismo que una función normal (el compilador suele copiarla en línea).
  • Guárdala con auto. std::function<int(int)> guarda «cualquier cosa que se pueda llamar» (por ejemplo, una lambda recursiva), pero es un poco más lento.
  • Prefiere lambdas cortas, y cuidado con [&] en una lambda que se devuelve o se guarda para después: las referencias a variables locales quedan colgando.

Código completo en C++

Compílalo y ejecútalo con:

g++ -std=c++17 -Wall -Wextra lambdas.cpp -o lambdas && ./lambdas

Para practicar

  1. Con std::count_if, cuenta cuántos números de numeros son pares.
  2. Escribe auto crearMultiplicador = [](int k) { … }; que devuelva una lambda que multiplique por k. Crea doble y triple y pruébalas.
  3. Ordena un std::vector<std::string> por longitud y, si empatan, alfabéticamente.
  4. Usa std::for_each con una lambda que capture [&maximo] para encontrar el mayor de numeros. ¿Qué pasa si capturas [maximo]?
  5. Cambia [b] por [&b] en crearSumador y compila con -fsanitize=address. ¿Qué te dice el sanitizador al llamar a sumarBase?
