Stack

The last one in is the first one out (LIFO, Last In, First Out). You will see std::stack and a linked stack built from nodes.

Last in, first out

Like a stack of plates: the last one you put on top is the first one you take off. You only work at one end, the top.

std::stack<int>: push adds on top, top reads the top and pop removes it, all in O(1). On an empty stack they don't warn you: ask empty() first.

You do push(4), push(8), push(15) and then pop() twice. What does top() return?

What does int x = stack.pop(); do?

A real use: balanced parentheses

The compiler checks that every (, [ and { is closed in order. With a stack it is easy: each opener is pushed, and each closer must match the last opener still open, which is exactly the top. It goes through the text once: O(n).

Why isn't "([)]" balanced, if it has one pair of each?

Inside: a linked list, with push

A stack can be built from nodes: the top pointer is the head of a linked list, and the top of the stack is the first node. push is exactly insertAtFront: create the node, make it point to the current top and move top. O(1), without traversing anything.

Why is the top at the front of the list and not at the end (using nodeAt(size - 1))?

pop: save, move and free

It is removing the head of the list: temp keeps the top, its value is read, top moves to the next node and the node is freed with delete. Unlike std::stack, this version returns the value and throws std::underflow_error if the stack is empty.

What happens if you do delete temp before top = top->next?

peek: look without removing

It returns the value of the node top points to, without changing anything: O(1). It is std::stack's top(), but on an empty stack it throws an exception instead of reading garbage.

The same buttons for both versions. Switch versions and compare: std::stack hides how it stores the values; in LinkedStack you see the nodes and the pointers.

  • Inside std::stack there is a std::deque (blocks of arrays). You can change it: std::stack<int, std::vector<int>> uses a vector. An array with a top index works too, but it has a fixed capacity.
  • Linked or array-based: the linked one never fills up and copies nothing when it grows, but each node asks for memory with new and stores an extra pointer. In practice, std::stack (with a deque or a vector) is usually faster.
  • Where it is used: the function call stack (and recursion), undo and redo in an editor, the browser's "back" button, evaluating expressions, checking parentheses and the depth-first search (DFS) of a graph.
  • If you need to remove from the other end (the oldest first), what you want is a queue.
