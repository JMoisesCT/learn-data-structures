Learn data structures by watching how they work

Every topic has an interactive animation that shows, step by step, what happens in memory while the code runs. The ideas work in any language; the examples are in C++.

Topics

How to use this site

  1. Read the idea. Each topic starts with a short explanation and an analogy.
  2. Run operations. Type a value, press an operation and watch the animation. Pause or step back whenever you want.
  3. Follow the code. The C++ line being executed is highlighted on the right.
  4. Compile the example. Each topic includes a complete program ready for g++, plus exercises.

What do I need to know?

The basics of C++: variables, if, loops, functions and classes. Pointers are explained when they show up (in the linked list). We recommend following the topics in order.
