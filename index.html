Aprende estructuras de datos viendo cómo funcionan

Cada tema tiene una animación interactiva que muestra, paso a paso, qué pasa en memoria mientras se ejecuta el código. Las ideas sirven para cualquier lenguaje; los ejemplos están en C++.

Temas

Cómo usar este sitio

  1. Lee la idea. Cada tema empieza con una explicación corta y una analogía.
  2. Ejecuta operaciones. Escribe un valor, pulsa una operación y observa la animación. Pausa o retrocede cuando quieras.
  3. Sigue el código. La línea de C++ que se está ejecutando se resalta a la derecha.
  4. Compila el ejemplo. Cada tema incluye un programa completo listo para g++ y ejercicios.

¿Qué necesito saber?

Lo básico de C++: variables, if, ciclos, funciones y clases. Los punteros se explican cuando aparecen (en la lista enlazada). Te recomendamos seguir los temas en orden.
