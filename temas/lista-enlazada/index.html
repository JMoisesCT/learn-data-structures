Lista enlazada

Una secuencia de nodos repartidos por la memoria. Cada nodo guarda un valor y un puntero al siguiente. Es la idea detrás de std::forward_list, y vas a ver qué hace cada operación con esos punteros.

Nodos que se apuntan entre sí

Piensa en una búsqueda del tesoro: cada pista dice dónde está la siguiente. No puedes saltar a la quinta pista; tienes que pasar por las cuatro anteriores.

struct Nodo {    int valor;    Nodo* siguiente;  // nullptr si es el último};

Cada nodo se crea con new donde haya lugar, así que no quedan uno junto a otro como las casillas de un vector. La lista solo guarda cabeza, la dirección del primero; el resto se encuentra siguiendo los siguiente.

Por eso, para leer la posición pos no hay una cuenta como en el vector: hay que dar pos saltos desde la cabeza. obtener(pos) es O(n).

¿Cuántas veces se ejecuta actual = actual->siguiente en obtener(3)?

insertarAlInicio: dos punteros y listo

Se crea el nodo, se lo hace apuntar al que hoy es el primero y se mueve cabeza hacia él. No importa si la lista tiene 3 nodos o un millón: son siempre los mismos pasos, O(1). (En el vector, insertar al inicio corre todos los elementos.)

¿Qué pasa si se cambia el orden y se hace cabeza = nuevo antes de nuevo->siguiente = cabeza?

insertarAlFinal: primero hay que llegar

Enlazar el nodo nuevo también es un solo puntero, pero la lista no sabe cuál es el último: actual tiene que recorrerla desde la cabeza hasta el nodo cuyo siguiente es nullptr. Ese recorrido hace que sea O(n). Si la lista está vacía, el nodo nuevo pasa a ser la cabeza.

¿Cómo podrías hacer que insertarAlFinal sea O(1)?

buscar(valor): nodo por nodo

actual avanza desde la cabeza comparando cada valor. Si llega a nullptr, se terminó la lista y el valor no está. En el peor caso revisa todos los nodos: O(n).

Si la lista estuviera ordenada, ¿sirve la búsqueda binaria como en el vector?

eliminar(valor): desenganchar y liberar

Para sacar un nodo, el nodo anterior tiene que apuntar al que sigue del borrado. Como los punteros van en una sola dirección, actual se detiene un nodo antes y mira actual->siguiente. Después, delete libera la memoria. Borrar la cabeza es un caso aparte: no tiene anterior, se mueve cabeza.

¿Lista o vector?

Ninguna es mejor en todo. Elige una operación y cambia la cantidad de elementos: cada barra es el trabajo que hace cada estructura (verde: la que hace menos).

La lista brilla cuando insertas o borras al inicio o junto a un nodo que ya tienes a mano. Para todo lo que necesite llegar a una posición, el vector gana, y casi siempre también al recorrer, por la caché.

Un programa recibe tareas y siempre atiende la más reciente primero (agrega y saca por el mismo lado). ¿Qué conviene?

  • Úsala cuando insertas y eliminas mucho al inicio, o junto a nodos que ya tienes localizados (por ejemplo, con un iterador guardado).
  • Es la base de otras estructuras: pilas, colas, listas de adyacencia de grafos y las cubetas de una tabla hash con encadenamiento.
  • Una ventaja poco obvia: insertar o borrar nodos no mueve a los demás, así que los punteros a otros nodos siguen siendo válidos (en un vector, al redimensionar, no).
  • Evítala si accedes por posición o recorres mucho: std::vector suele ser más rápido por la caché, y gasta menos memoria por elemento. Mide antes de elegir.
  • std::list es la versión doblemente enlazada: cada nodo también apunta al anterior, así que se puede recorrer en los dos sentidos y borrar un nodo sin buscar su anterior.

Código completo en C++

Compílalo y ejecútalo con:

g++ -std=c++17 -Wall -Wextra lista_enlazada.cpp -o lista_enlazada && ./lista_enlazada

Para practicar

  1. Agrega un puntero cola al último nodo para que insertarAlFinal sea O(1). ¿Qué otros métodos tienes que actualizar?
  2. Escribe void invertir() que dé vuelta la lista cambiando solo punteros, sin crear nodos. (Pista: necesitas tres punteros: anterior, actual y siguiente.)
  3. Escribe int tamano() const, primero con un ciclo y después de forma recursiva.
  4. Cambia eliminar para que borre todas las apariciones del valor, como std::forward_list::remove.
