Vector dinámico

Un arreglo que crece solo. Guarda los elementos uno junto a otro en memoria, así que llegar a cualquier posición es inmediato. Es la idea detrás de std::vector.

La idea

Un arreglo normal de C++ (int a[10]) tiene un tamaño fijo. Un vector dinámico guarda tres cosas:

  • datos: un puntero a un arreglo reservado con new.
  • tamano: cuántos elementos hay realmente.
  • capacidad: cuántas casillas tiene el arreglo reservado.

Mientras tamano < capacidad, agregar al final es solo escribir en la siguiente casilla. Cuando se llena, se reserva un arreglo del doble de tamaño, se copia todo y se libera el viejo.

Como los elementos están contiguos, datos[i] se calcula con una suma: dirección de inicio + i × tamaño de un int. Por eso el acceso por índice es O(1). Lo caro es insertar o eliminar en medio, porque hay que desplazar los elementos.

Pruébalo paso a paso

Usa Posición para insertar y eliminarEn. Prueba también una posición inválida (por ejemplo 9) para ver la excepción. Agrega dos valores seguidos para ver redimensionar.

Duplicar la capacidad hace que, en promedio, agregarAlFinal sea O(1): las copias caras ocurren cada vez con menos frecuencia. A esto se le llama costo amortizado.

Complejidad

OperaciónTiempoPor qué
obtener(i) / v[i]O(1)Se calcula la dirección directamente.
agregarAlFinalO(1) amortizadoCasi siempre hay espacio; a veces se copia todo.
insertar(pos, x)O(n)Se desplazan los elementos a la derecha de pos.
eliminarEn(pos)O(n)Se desplazan los elementos para cerrar el hueco.
buscar(x)O(n)Hay que revisar casilla por casilla (si no está ordenado).

¿Cuándo usarlo?

  • Es la estructura por defecto en C++: si dudas, usa std::vector.
  • Cuando necesitas acceder por posición y casi siempre agregas al final.
  • Evítalo si haces muchas inserciones o eliminaciones al inicio o en medio: considera una lista enlazada o una std::deque.

En C++ real: std::vector<int> v; v.push_back(10); v.insert(v.begin() + 1, 15); v.erase(v.begin());

Código completo en C++

Compílalo y ejecútalo con:

g++ -std=c++17 -Wall -Wextra vector_dinamico.cpp -o vector_dinamico && ./vector_dinamico

Para practicar

  1. Agrega void eliminarAlFinal(). ¿Cuál es su complejidad?
  2. Haz que el vector se reduzca a la mitad cuando tamano sea menor que capacidad / 4. ¿Por qué no a la mitad exacta?
  3. Cambia redimensionar(capacidad * 2) por redimensionar(capacidad + 1) y cuenta cuántas copias se hacen al agregar 1000 elementos.
